# COPOXJR — Cinematic Futuristic Website

Responsive single-page website with a custom SVG emblem, neon blue/cyan/purple styling, animated hero, feature cards, About section, social links, mobile navigation and scroll reveal effects.

## Files
- `index.html` — page content
- `style.css` — responsive layout, visuals and animations
- `app.js` — navigation and scroll interactions
- `assets/logo.svg` — custom logo and favicon

## Publish with GitHub Pages (iPhone-friendly)
1. Download this ZIP to the Files app and tap it once to extract.
2. Open your GitHub repository and upload the extracted files and `assets` folder (not the ZIP itself).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then press **Save**.
6. Wait for GitHub Pages to publish and open the URL it shows.

## Customize
Replace the sample social links in `index.html` with your own profiles. Edit the copy in the same file and adjust colors at the top of `style.css`.

This is a frontend landing page. It does not include real login, database, or backend features. The logo and graphic elements are locally included; Google Fonts or remote images are not required.
